# Editorial review rules

## Language

The website language is German.

* Correct clear mistakes without flattening the author's voice.
* Replace HTML entities such as `ü` with the actual character when they represent ordinary text.
* Preserve deliberate dialect, colloquial phrasing, code-switching, quoted text, and period language.
* Explain substantial rewrites before applying them when meaning or tone could change.

## Historical integrity

Old posts are historical documents.

Prefer this pattern:

1. preserve the original statement
2. add a clearly marked editorial note
3. explain what changed and, when known, when it changed

Do not retroactively rewrite an old observation into present-day knowledge.

## Structure

Check:

* one coherent page title supplied by the layout/frontmatter
* logical heading hierarchy in the body
* short enough paragraphs for web reading without mechanically fragmenting prose
* lists only where they improve comprehension
* no empty headings
* no heading used merely for visual styling

## Facts

Verify current facts only when the post or editorial note presents them as current.

For historical facts:

* distinguish what the author reported at the time
* do not "correct" a contemporaneous account based only on hindsight
* flag material uncertainty
* use primary or authoritative sources where verification is necessary

## Links

For every link, classify:

* valid and useful
* redirected but acceptable
* replaceable with a better canonical source
* broken but historically meaningful
* broken and removable
* unsafe or inappropriate

Do not replace an old link with a modern page that does not support the same claim.

## Editorial notes

Use the site's editorial-note component or syntax when available.

A note should contain:

* a concise reason for the note
* the relevant current or historical clarification
* the editorial review date when repository convention calls for it

Keep the note distinct from the original article.
