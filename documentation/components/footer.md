# Footer

`src/components/layout/footer/Footer.astro` is the shared site footer. It includes links to the Samui? Samui! [Mastodon](https://mastodon.social/@samuisamui) and [Bluesky](https://bsky.app/profile/samui-samui.de) profiles, the [Threads profile](https://www.threads.com/@samuisamui_de), the [Reddit community](https://www.reddit.com/r/samuisamui/), the [Facebook Page](https://www.facebook.com/samui.samui), and the [Instagram profile](https://www.instagram.com/samuisamui_de), above the sound toggle and copyright line.

The social links use Mastodon, Bluesky, Reddit, Threads, Facebook, and Instagram SVGs from the installed `@iconify-json/simple-icons` collection, rendered at build time through `astro-icon`. They require no browser-side icon requests or social embeds. Each link has a German accessible name, a decorative icon, a 44px hit area, and a visible keyboard focus indicator. Links open in a new tab or window with `target="_blank"` and `rel="me noopener noreferrer"`. Their accessible names announce the new tab, and `me` identifies the site's social destinations.

The links reuse the existing foreground, accent, primary, background, medium radius, and spacing tokens. Profile URLs are public presentation data; the footer does not read Posthaste credentials or dotenv files. Analytics remains at the existing end-of-page position.

Social links use the shared `Tooltip` component in interactive mode, placed above the icons. The network-specific German messages are `Folge mir auf Mastodon`, `Folge mir auf Bluesky`, `Tausch dich auf Reddit aus`, `Folge mir auf Threads`, `Folge mir auf Facebook`, and `Folge mir auf Instagram`. Each link references its tooltip through `aria-describedby`; the wrapper adds no extra tab stop. The social trigger wrappers disable pointer events on the shared expanded-hit-area pseudo-element so it cannot intercept link clicks. Native `title` attributes are omitted so browser tooltips do not compete with the site tooltip. The shared controller handles hover, keyboard focus, Escape dismissal, viewport positioning, and Astro navigation.

Public social destinations are defined in `src/config/social.ts`. Import `SOCIAL_NETWORKS` through `@config/social` to reuse the ordered, readonly list. Each entry has a stable lowercase `id`, a display `name`, an HTTPS `href`, a Simple Icons `icon`, and German `tooltip` text. `SocialNetworkId` derives the supported ID union from this list, so later intent-link code can select a network without relying on its display name or profile URL. Intent links are not implemented by this configuration change. Keep secrets and publishing defaults in the independent Posthaste setup. The footer derives tooltip IDs from the stable network IDs.
