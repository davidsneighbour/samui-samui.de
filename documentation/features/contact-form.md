# Contact form

The contact page renders editorial copy in the normal prose wrapper, but `src/components/features/contact/ContactForm.astro` sits outside that wrapper so form controls and helper text can keep their compact spacing.

The form posts to `/api/contact`, which the Cloudflare Worker `samui-samui-api` handles (`src/workers/api/contact.ts`, route and settings in `wrangler.jsonc`; see [Hosting architecture](../hosting/architecture.md)). The Worker checks the honeypot field, the same-origin `Origin` header, field presence and length limits, the local spam heuristics, and the Cloudflare Turnstile token (with the visitor IP from `CF-Connecting-IP`), and then sends the React Email notification through the Resend API with `fetch()`. Responses are JSON for the enhanced form (`Accept: application/json`) and a minimal HTML page when the browser submits natively; both carry meaningful status codes (`400` invalid or suspicious, `403` foreign origin, `405` wrong method, `413` oversized body, `500` missing secrets, `502` Resend failure).

Privacy contract, relied on by the privacy policy: the visitor IP goes only to Turnstile (`remoteip`), never into the notification email, and Worker logs never contain form fields, IP addresses, or user agents. A Resend failure logs only the HTTP status and Resend's error `name`, because Resend's error `message` can quote form fields such as the email address. `src/workers/api/test/api.test.ts` covers both rules.

The spam heuristics (`src/workers/api/lib/spam.mjs`), the renderer (`src/workers/api/lib/email.mjs`), and the React Email template (`src/workers/api/emails/contact-notification.tsx`) live next to the Worker. They were shared with the Netlify Function until the Netlify clean-up ([#1784](https://github.com/davidsneighbour/samui-samui.de/issues/1784)).

Secrets are Worker secrets, never committed: `RESEND_API_KEY`, `TURNSTILE_SECRET`, `CONTACT_EMAIL_FROM`, `CONTACT_EMAIL_TO`, and the optional comma-separated `CONTACT_EMAIL_BCC`. `CONTACT_EMAIL_SUBJECT_PREFIX` and `CONTACT_EMAIL_TIMEZONE` are plain variables in `wrangler.jsonc`. The public `TURNSTILE_SITE_KEY` is read at build time, so it must be present in the build environment (local `.env` or the CI secret). See [Deployment](../hosting/deployment.md#secrets-and-configuration).

Links inside the form therefore do not receive `prose-a:text-link` automatically. Any form-local legal or helper copy with anchors must style those anchors with the global `link` token so the contact page keeps the same reddish link treatment as the surrounding Markdown.

Text inputs and textareas intentionally use the normal 16px body size rather than the compact helper-text size. This avoids iOS Safari's focused-field zoom while labels and legal copy can remain visually smaller.

Submit feedback uses the existing `muted`, `border`, `muted-foreground`, `primary`, and `link` tokens instead of standalone success/error hex colors, following the same split as the [Notice](../components/notices.md) variants. Success keeps the neutral `border` token and shows a Lucide `circle-check` icon in `muted-foreground`. Error uses `border-primary/40` (as `color-mix(in oklab, var(--color-primary) 40%, transparent)`) and a `circle-alert` icon in `link`. The message text carries the actual result, and the icon separates the two states without relying on colour alone. Earlier, success had a full brand-red border and read like an error ([#1786](https://github.com/davidsneighbour/samui-samui.de/issues/1786)). The icons are `aria-hidden`; screen readers get the result from the `role="status"` text. Icon contrast against `muted` is at least 4.1:1 in both themes. The status box enters over 200ms (opacity plus a 4px rise, `cubic-bezier(0.2, 0, 0, 1)`) through `@starting-style`, because it appears below the button where the visitor is not looking. It hides instantly on resubmit. See the Motion section in `DESIGN.md`.

While the request runs, the form carries `aria-busy="true"`. The submit button is disabled but stays at full opacity, and its Send icon is replaced by a Lucide `loader-circle` that spins at 700ms per turn. Without this, only the loading sound showed that sending was in progress, and visitors with sound off saw a dimmed button that looked unavailable. Under reduced motion, the global rule in `theme.css` leaves a static loader icon.

Cloudflare Turnstile legal copy is shown only when `TURNSTILE_SITE_KEY` is set. Its privacy-policy and terms links are colored with `var(--color-link)` and underlined in the component stylesheet because the disclaimer is not prose content.
